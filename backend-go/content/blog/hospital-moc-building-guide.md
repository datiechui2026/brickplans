# 积木医院MOC搭建教程：急诊入口、病房与手术室的完整做法

医院是街景小镇里最需要"秩序感"的建筑。它不像花店那样浪漫，也不像影院那样张扬，但一栋细节到位的**积木医院MOC**，却能让整条街立刻显得完整而可信。这篇教程会从急诊入口、病房、手术室到屋顶十字标识逐一拆解，带你搭出一栋"从外到内都像医院"的迷你医院。

## 一、外立面与急诊入口：第一眼就要"像医院"

医院立面的辨识度主要来自三点：白色主调、横向长窗和醒目的急诊入口。墙体建议用米白或浅灰基础砖打底，楼层之间夹一条深色腰线，营造出干净利落的医疗感。入口是重点：急诊入口要做成**有坡道的无障碍通道**，用斜面板拼出缓坡，坡道尽头配一扇推拉门（透明玻璃门板加滑轨件），门上方挂一盏指示灯箱和"急诊"字样招牌。门口再停一辆急救车的话，医院的忙碌氛围立刻就出来了。

## 二、病房区：床位、床头柜与输液架

病房是医院内部的主角。标准做法是一层做两到三间病房，每间摆一张病床：床架用浅色板砖搭出，床垫用白色弧面件，床头柜用 1×2 深棕色砖，柜上放一只小水杯和一瓶花。病床上方架一根输液架——用细圆杆件加挂钩，挂一只透明小圆件当输液袋，细节虽小，却是病房的灵魂。墙上再贴一块病床号牌（用印刷件或贴纸），窗台放一盆绿植，病房的"温度"就出来了。走廊可以用深色地砖铺一条中轴线，让内部更有纵深感。

## 三、手术室：无影灯是最大亮点

真正让医院 MOC 出彩的往往是手术室。手术室要营造"无菌"的氛围：整体用白砖加淡绿或淡蓝点缀，正中摆一张手术台（白色平板加两侧微抬的边板），台面上放一顶**无影灯**——用透明圆件叠在可弯折的关节件上，从上方垂下，再在灯头卡几颗白色圆点件模拟灯光，无影灯一装，手术室立刻有了专业感。旁边配一个器械台、一台心电监护仪（深色板加圆点显示屏）和一盏可旋转的落地灯，天花板四周留一圈灯槽，整间手术室的真实度瞬间拉满。

## 四、屋顶十字标识与整体动线

医院的屋顶标识往往被忽略，却是街景里"远处就能认出这是医院"的关键。建议在屋顶正中竖一座小型塔架或立一块大板，板上用 SNOT 技巧横着拼出**红色十字标识**，四角再装一圈小灯件；如果做的是转角医院，十字标还可以换成带斜面的立体件，让标识从两个方向都能看到。动线设计上，记得把急诊入口放在一楼临街一侧，病房安排在安静的内侧，手术室放在二楼靠后，人仔和"患者"的进出路线一目了然，整栋楼才真正"能用"。

## 五、搭建顺序与避坑提醒

推荐顺序：底板与楼层分区 → 病房区与床位 → 手术室与无影灯 → 急诊入口与坡道 → 外立面与长窗 → 屋顶十字标识与灯光走线。三个高频翻车点：一是只做外立面不做内部，掀开屋顶空空如也；二是急诊入口做成普通台阶，少了无障碍坡道，医院感大打折扣；三是十字标识平贴屋顶，远处根本看不清。记住**先内后外、坡道入口、立体十字**这三点，你的**积木医院MOC**就能在小镇里稳稳立足。
