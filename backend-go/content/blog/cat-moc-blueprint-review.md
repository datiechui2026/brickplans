# 积木猫MOC图纸推荐：用积木打造你的专属猫咪

## 开场

猫大概是积木里最难"还原"的动物：体型本来简单，全靠神态撑着——差一块弧形砖，气质就从猫变成狗。这两年**积木猫MOC图纸**出得挺多，我挑了坐姿、伸展、睡觉、行走加头雕五款对比，重点看脸部表情和毛色怎么处理。

## 一、猫咪MOC的设计要点

### 1.1 猫咪体型特征

猫咪的体型优雅灵动，不同品种的**积木猫**在体型上各有特点：

- **头部**：圆形或楔形，因品种而异
- **耳朵**：三角形，位置和大小是品种区分的关键
- **眼睛**：大而圆，是猫咪表情的核心
- **身体**：柔韧修长，肌肉线条流畅
- **尾巴**：长而灵活，是表达情绪的重要器官

### 1.2 品种差异

**猫咪MOC**设计时需要考虑不同品种的特征：

- **英短/美短**：圆脸、圆眼、短鼻、结实的身材
- **暹罗猫**：楔形脸、蓝眼睛、修长的身形
- **波斯猫**：扁脸、长毛、圆润的体型
- **橘猫**：圆润的体型，温暖的颜色
- **黑猫**：神秘优雅，全身漆黑

## 三、猫咪MOC搭建技巧

### 3.1 面部表情塑造

**积木猫**的表情是决定作品成败的关键：

1. **眼睛**：使用印刷件或贴纸表现不同的眼神——圆眼（惊讶）、半眯眼（慵懒）、细长眼（警觉）
2. **鼻子**：使用粉色小三角形件或1x1粉色圆形颗粒
3. **嘴巴**：使用弧形砖搭建"W"形嘴巴，表现猫咪的可爱表情
4. **胡须**：使用线状零件或细长杆件，插入嘴部两侧

### 3.2 毛色与纹理

- **单色猫**（黑、白、灰）：使用同色系不同深浅的砖块创造层次感
- **双色猫**（黑白、橘白）：注意色块的分区和过渡
- **三花猫**：使用三种颜色的砖块随机搭配，模拟三花猫的斑纹
- **虎斑猫**：使用条纹砖块或通过砖块排列创造条纹效果

### 3.3 可动结构

- **颈部**：使用球形关节，实现头部转动和倾斜
- **四肢**：使用科技销连接，实现前后摆动
- **尾巴**：使用串珠件或柔性管件，实现弯曲和摆动
- **耳朵**：使用铰链件，实现耳朵的转动（表现猫咪的情绪变化）

## 四、猫咪MOC图纸选择建议

### 4.1 按猫咪品种

- **英短/美短**：选择圆脸造型的图纸
- **暹罗猫**：选择楔形脸、修长身体的图纸
- **橘猫**：选择圆润造型的图纸
- **黑猫**：选择修长优雅的图纸

### 4.2 按用途

- **展示摆件**：选择坐姿或站姿的猫咪，尺寸适中
- **把玩互动**：选择可动关节较多的图纸
- **礼物赠送**：选择迷你钥匙扣或小型猫咪图纸
- **亲子搭建**：选择零件数少、难度低的图纸
