# MOC图纸教程：从看图到拼装的完整新手指南

很多刚入坑的朋友看到一份MOC图纸就懵：满屏的格子、箭头、零件编号，不知道从哪下手。其实MOC图纸并不神秘，它和说明书一样，只是信息密度更高。这篇 **MOC图纸教程** 会把看图的每个环节拆开讲清楚，让你拿到图纸就能动手。

## 一、先看懂步骤图：凸点朝上，按图索骥

MOC图纸最常见的画法是"俯视图 + 分层图"。记住三个关键点：

- **凸点（stud）朝上**：俯视图里每个小圆点代表一个凸点，零件按这个方向摆放，错一个方向后面就全歪。
- **箭头代表插入方向**：箭头指向哪里，零件就往哪里按；带弧线的箭头通常表示"卡进去再压平"。
- **高亮层只拼当前步骤**：每张图会把"新加的部分"用深色高亮，旧的部分用浅色或轮廓表示。你只需要盯着高亮部分拼，不要被旧零件干扰。

如果图上出现"x2""x4"标注，说明这一步要重复拼多个相同组件，先拼好组件再装到主体上，效率更高。

## 二、零件清单（BOM）怎么读：编号比名称重要

几乎每份MOC图纸都附有零件清单（BOM），读懂它就不用来回翻图猜零件。常见字段如下：

| 字段 | 含义 | 举例 |
| --- | --- | --- |
| Part Number | 零件编号 | 3001（2x4基础砖） |
| Qty | 数量 | 12 |
| Color | 颜色名称或代码 | Red / 21 |
| Category | 零件类别 | Bricks / Plates / Tiles |

找零件时**以编号优先**，因为同一种砖有无数颜色和尺寸，名称经常对不上号。建议先按编号把零件分袋装好，拼装时按步骤取用，省得翻箱倒柜。

## 三、颜色代码和"格子数"计数

MOC图纸里的颜色通常有两种写法：英文名称（如 Dark Bluish Gray）或乐高官方色号（如 85）。新手最容易犯的错是"看着像"——深灰和浅灰、土黄和橙黄在成品图上很像，但混用会破坏整体观感。拼之前把颜色代码和实物一一核对一遍。

尺寸计数则靠"格子"：图纸上的零件跨度以凸点数量为单位，例如"2x4"就是宽2个凸点、长4个凸点。拼大底座时先数清楚格子数，再决定用几块砖拼接，避免拼到一半发现尺寸对不上。

## 四、怎么按比例缩放：大比例难，小比例更难

想把图纸放大或缩小，这是很多人踩坑的地方。两个实用原则：

- **缩小（如1:1改成1:2）**：不能简单"每个零件换成一半"，因为乐高零件尺寸是离散的，没有"半格"砖。要先算出总凸点数，再重新分配零件，必要时改变拼搭结构。
- **放大（如改成2:1）**：相对容易，把每个1x1的区域替换成2x2的板，但内部结构、连接点要重新设计，否则一碰就散。

最省力的做法是：直接用官方或社区提供的"零件清单 + 步骤图"，在BrickPlans这类社区里找同款图纸的其他比例版本，比自己硬算省事得多。

## 五、新手最容易犯的四个错

1. **颜色凭感觉**：不核对色号，成品出现色差。
2. **方向搞反**：凸点方向错了，拆了重拼浪费时间。
3. **忽略数量**：BOM没看全，缺件了才发现。
4. **贪大求全**：第一次就挑战几千片的大作，中途弃坑。
