# 乐高MOC展览指南：从参观到参展的完整攻略

如果说图纸和零件是 MOC（My Own Creation）玩法的日常，那么**乐高MOC展览**就是玩家们的"年终大考"和"联欢会"。在一场线下展览里，你既能看到大神们动辄上万颗粒的史诗级作品，也能结识一群跟你一样在深夜为某个结构挠头的同好。很多玩家第一次逛完展，心里就种下了"我也要带作品去参展"的种子。这篇指南就带你把"看展"和"参展"这两件事都整明白。

## 什么是乐高MOC展览

所谓 MOC 展览，就是由积木爱好者组织、以玩家原创作品为主要展品的线下活动。它和商场里那种"把官方套装摆一排"的展示完全不同——这里的每一件作品背后都是一个真实玩家数周甚至数月的构思与搭建。

常见的展览形态主要有这几类：

| 类型 | 特点 | 代表形式 |
| --- | --- | --- |
| AFOL节 | 成人积木爱好者聚会，作品水平高、交流氛围浓 | AFOL Convention、玩家聚会 |
| 砖块展 | 综合大型展会，常与商业品牌联动 | Brick Festival 等 |
| 主题展 | 围绕某个 IP 或题材（街景、军事、科幻） | 街景展、机甲展、微缩场景展 |
| 区域沙龙 | 城市级小展，新玩家友好、门槛低 | 本地俱乐部联展 |

## 如何找到身边的乐高MOC展览

- **关注俱乐部与社群**：各大城市的 MOC 俱乐部通常会定期办展，加入本地积木群能第一时间收到招募和票务信息。
- **留意官方与媒体渠道**：乐高官方及国内积木媒体会发布展会日历，部分商场也会承办主题展。
- **线上平台搜线索**：在 B站、小红书上搜"城市名+积木展"，往往能发现玩家整理的看展攻略。
- **关注 [brickplan.cn](https://brickplan.cn)**：社区里常有玩家晒展况、分享参展作品的图纸，跟着逛一圈你的收藏夹就满了。

## 看展攻略：别让一次好展白逛

### 1. 提前做功课

- 确认展期、票价、是否需要预约，热门场次周末大概率爆满。
- 查清展馆动线，把想重点看的作品和互动环节提前圈出来。

### 2. 现场怎么"看"

- **先宏观后微观**：先退远两步看整体造型和布局，再凑近看细节和结构，很多妙处藏在转角处。
- **多问、多拍**：大部分作者很乐意分享搭建思路，礼貌请教往往能换来一堆干货；拍照前先确认是否允许。
- **留意"说明书之外"的巧思**：比如隐藏的 SNOT 技法、巧妙的悬挂结构，都是可以回家复刻的学习素材。

### 3. 回来之后

把拍到的灵感整理进素材库，用 [brickplan.cn](https://brickplan.cn) 的图纸库对照学习，把看展的冲动转化成下一次搭建的选题。

## 怎么把自己的作品送去参展

很多玩家以为参展门槛很高，其实并非如此。大部分展览的投稿流程可以概括为四步：

1. **准备作品**：完成度高、结构牢固、主题明确的 MOC 作品，建议提前做好防尘收纳和搬运方案。
2. **找到招募渠道**：关注主办方发布的参展公告，或通过俱乐部统一报名。
3. **提交资料**：一般需要作品照片、尺寸、颗粒数量简介，部分展览还会要求提供运输和布展方案。
4. **现场布展**：按主办方规划摆放，贴好作者信息卡，准备好现场讲解。

### 参展要注意的细节

- **结构要经得起"折腾"**：展览期间的搬运、观众触碰都是考验，脆弱的部件务必加固或加展示罩。
- **守时守约**：布展撤展都要遵守时间安排，这是圈内最看重的基本素养。
- **心态放平**：第一次参展结果没那么重要，认识人、听反馈、攒经验才是最大收获。

## 写在最后

一场**乐高MOC展览**，是一群成年人认真搭积木的最好证明。无论你是带着孩子去看热闹的新手，还是揣着图纸去投稿的资深玩家，走进展馆那一刻，你都能感受到积木这个爱好最纯粹的快乐。如果看完这篇你也心痒了，不如先从社区里找一场最近的本地小展开始——说不定下一次，你也会是展台上那位被围观的作者。
