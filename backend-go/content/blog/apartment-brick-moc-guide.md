# 公寓积木MOC：多层公寓的户型布局与细节搭建指南

公寓是街景积木里最"耐看"也最"磨人"的题材。小独栋随便搭都顺眼，一上多层就露馅：各层对不齐、室内空荡荡、阳台窗框歪歪扭扭。这篇**公寓积木MOC**指南，把户型、模块化楼层、内外墙、阳台窗户和迷你家具一步步讲透，照着做能少拆三遍。

## 先定户型：尺寸和分区决定一切

动工前先在底板上画出平面图，公寓积木MOC最忌讳边搭边改。常见做法是每户 16×16 或 20×20 格，一层放两户。分区按"动静分离"来：靠窗一侧留给客厅和卧室，中部做厨房与卫生间。厨房和卫生间用 2×2 格垫高一层，模拟地面高差，视觉上立刻分区。楼梯间单独占 4×8 格，从一层贯通到顶，别让住户从别人家阳台进屋。

## 模块化楼层：一层搭好，层层复制

多层公寓的关键是"一次设计、重复拼装"。户型定好后，把每层做成独立单元：地板用板件铺满，四角用带孔砖做定位凸点，上一层的地板刚好卡住下一层的凸点，这样几层叠起来严丝合缝，还能整层抽出来改内饰。每层之间用 1×2 带孔砖在四角竖向咬合，防止错位。想加高楼层，只需要多做几块相同的"楼层板"，整栋公寓积木MOC的层数随你定。

## 内外墙结构：内墙矮半层，外墙留窗位

公寓外墙做"双层墙"效果最好：外皮用浅色砖模拟涂料或砖墙，内衬一层板件做窗台厚度，窗户就嵌进两层之间，立体感立刻出来。内墙比外墙矮半层，方便从楼顶往下看室内。转角处用转角砖上下错缝，避免四条角线成通缝。每层外墙顶部留一行凸点，供上一层地板咬合，这个细节别省。

## 阳台与窗户：公寓的门面

阳台是公寓最有生活气的地方。悬挑阳台用板件做底，用 1×2 带孔砖和科技销固定在墙体上，比直接搭在墙边结实。围栏用 1×4 栅栏件加横杆，矮矮一道就行。窗户关键是"缝"：窗框间隔全程一致，先用深色板件排好窗框模板，再嵌透明 1×2 玻璃砖，逐层对位，越往上越整齐。想更真实，玻璃后垫亮银色板当反光。

## 楼梯间与迷你家具

楼梯间做单跑或 L 形：每级用 1×2 板件垫高两格，配 1×1 板件做台阶，平台用 2×4 板件，扶手用细杆件，别挡人仔通行。迷你家具按房间功能配：客厅沙发用 2×4 板件加靠背、茶几 2×2、电视用 1×2 透明砖；厨房灶台 2×2、冰箱 1×2 高砖；卧室床 2×4 板件加枕头、床头柜 1×1；卫生间浴缸 2×3、洗手台 1×2。每户家具配色错开一点，整栋楼才有"住了不同的人"的感觉。

## 避坑清单

最后列几条高频坑：户型没定就开搭，返工概率极高；层间定位凸点省掉，楼层对不齐；阳台悬挑没加固，一碰就掉；窗框间距中途改尺寸，越往上越歪。按"先户型、再楼层板、后内外墙、最后家具"的顺序搭公寓积木MOC，基本稳。
