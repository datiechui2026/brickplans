# 积木街景搭建教程大全：从入门到进阶的完整MOC指南

街景（Street View）是积木MOC中最受玩家欢迎的题材之一。一栋带咖啡馆的转角楼、一条绿树成荫的小巷、一座亮起暖黄灯光的复古店铺……把梦想中的街角用积木亲手搭出来，正是 MOC（My Own Creation，我的原创作品）最大的乐趣所在。今天这份**积木街景搭建教程大全**，就从地基到灯光，为你梳理一套完整、专业又实用的搭建流程。

## 为什么街景适合作为MOC入门题材

街景类MOC的**容错率极高**，即便比例或结构略有偏差，整体观感依然在线，非常适合新手练手：

- **题材熟悉**：街角、店铺、住宅每天都在身边，参考资料随手可得。
- **模块化易拆改**：一栋楼可分楼层、分房间搭建，出错只需局部返工。
- **展示性强**：单个建筑完成即可上柜，连成街景更出效果。

## 搭建前的准备：规划与配色

### 确定比例与底盘尺寸

主流街景多采用 **1:48 或 1:64 比例**，底盘以 32×32 孔距起步。建议先用图纸确定**地基范围与楼层高度**，再动手。

### 配色方案先行

- 外墙与内饰采用**同色系深浅搭配**，避免花哨。
- 用**一两个跳色**（如红砖墙配白窗框）制造记忆点。
- 屋顶、招牌、门窗统一风格，街景整体才协调。

## 核心搭建步骤

### 第一步：地基与墙体

- 先铺**底板**，预留门窗洞口，再用标准砖砌外墙。
- 转角处用**转角砖**或柱子加强结构，防止墙体歪斜。
- 楼层间加装**平板作为楼板**，为上层承重。

### 第二步：内饰与隔层

- 一层做**店铺或客厅**，二层做**卧室或书房**，功能分区更真实。
- 用 **SNOT（Studs Not On Top）** 技巧横向堆砖，做出窗台、柜台等细节。

### 第三步：细节装饰让街景"活"起来

- 店招、雨棚、绿植、路灯、邮箱等小件是**点睛之笔**。
- 加入**人仔与街景互动场景**，比如路人在窗前聊天、店主在门口摆放商品。
- 用各类**小零件模拟杂物**，越细碎越显真实。

### 第四步：灯光与整体布景

- 在店铺窗户后加**暖色灯砖**，夜间效果立现。
- 多栋建筑拼成街角时，注意**风格统一 + 高低错落**，避免视觉单调。

## 常见问题与避坑建议

- **墙体倾斜**：多为底砖没对齐，拆掉重铺并加强角柱即可。
- **比例失衡**：按图纸标尺搭建，别凭感觉放大缩小。
- **零件不够**：优先用通用件，特殊件后期再补齐。
