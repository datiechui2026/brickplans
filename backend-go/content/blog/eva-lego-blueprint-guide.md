# EVA乐高图纸入门：初号机搭建全流程与机甲拼搭技巧

《新世纪福音战士》的机体设计融合了生物质感与机械美学，堪称机甲动画的里程碑。很多积木玩家都渴望用砖块复刻初号机，却苦于找不到合适的**EVA乐高图纸**。这篇指南会从零件准备、搭建顺序到核心技术，帮你从零完成一台属于自己的EVA-01。

## 一、搭建前需要准备什么

在下载**EVA乐高图纸**之前，先确认手头的零件储备。以常见的1:35比例初号机为例：

| 零件类型 | 主要用途 | 建议数量 |
| --- | --- | --- |
| 紫色板砖 | 主装甲 | 400+ |
| 绿色弧形砖 | 四肢关节 | 200+ |
| 科技件与销 | 内部骨架 | 300+ |
| 透明蓝色砖 | AT力场特效 | 100+ |
| 球形关节件 | 肩、髋可动 | 20+ |

零件不足时不必强求原色，用相近色替代同样是MOC的乐趣所在。零件备齐后，建议按"骨架、装甲、细节"三步走：先用科技件搭出可站立的内骨架，再逐块覆盖紫色板砖，最后补上眼部件与印刷件，这样拆装调整都方便。

## 二、初号机搭建的三大核心技术

**EVA乐高图纸**的难度主要来自三处。第一是修长的身形比例——EVA与高达的方正躯干不同，需要大量SNOT技巧让砖块侧向堆叠，才能塑造出四肢修长、肌肉线条流畅的机体轮廓。第二是肩部拘束器，它是初号机的标志性结构，建议做成可拆卸模块，方便在普通形态与暴走形态之间切换，暴走时换上红色透明眼部件即可。第三是生物质感，用弧形砖与斜面砖交替组合，模拟皮肤下的肌肉走向，避免机体显得过于"方块化"。

## 三、AT力场与场景氛围

EVA之所以迷人，还在于独特的AT力场。搭建时用透明蓝色与紫色砖块围成环状，悬浮在机体周围，配合深色底座能营造出战斗的压迫感。进阶玩家还可以为初号机配一个插入栓舱场景——驾驶舱用圆柱砖拼成，可插入机体背部，还原度瞬间拉满。若想进一步练手，二号机的红色涂装与使徒力天使的几何体结构也是不错的挑战方向。
