# 积木寿司店MOC评测：日式街景美食主题的细节天花板

街景题材里，美食店铺永远是最讨喜的一类——而日式寿司店更是其中的"细节天花板"。这期**积木寿司店MOC评测**，我们实际搭了一座由社区设计师出图的日式街角寿司店，从开盒到摆柜逐一打分，给想入手的你一个明确答案。

## 一、包装与零件：开盒第一印象

图纸采用 **1:48 街景比例**，整店约 1800 个零件，分 6 包拼装。零件以**米白、深棕、墨绿、浅木色**四色为主，日系配色一眼到位。印刷件质量是亮点：店招上的"寿司"字样、菜单板上的价格牌都是印刷件而非贴纸，耐玩不易翘边，这点非常加分。缺件率几乎为零，分包颗粒分明，整体给 **9/10**。

## 二、建筑结构：小而精的和风立面

店铺占地 16×16 孔距，两层结构。一层是开放式料理台，二层是阁楼与露台。立面设计相当讲究：

- **屋檐**：深棕色瓦片斜面砖层层叠压，做出日式"唐破风"式檐口，从正面看弧线非常顺滑。
- **门帘（暖帘）**：用两块 1×3 深蓝色板并排做门帘，中间夹缝透光，推开即见柜台——这是整店最惊艳的设计。
- **障子窗**：二层用白色框架 + 半透明板做格子窗，打上暖光后，光影效果直接拉满。

结构上墙体用内衬板加固，二楼承重稳妥，扣合度好，无外鼓现象，建筑给 **9/10**。

## 三、美食细节：回转寿司是全场高光

作为**街景美食主题**作品，这间寿司店最出彩的就是**回转寿司带**。一条沿柜台环绕的传送带用履带件（Tread）拼成，上面摆着：

- 三文鱼寿司（橙色 1×1 圆件 + 白色米粒底）；
- 玉子烧（黄色 2×2 板叠两层）；
- 章鱼烧（棕白相间的 1×1 圆件）。

传送带还能手动转动，互动性极强。此外，后厨里的小人仔正在捏寿司，厨师帽、围裙一个不少，料理台上有芥末绿、生姜粉等小件点缀。美中不足是寿司品种偏少，想要"满桌盛宴"得自己加菜，细节给 **8.5/10**。

## 四、灯光与整体氛围

加装暖黄色灯条后，暖帘与障子窗透出的光晕非常迷人，深夜街景一摆，日式小店的人间烟火气扑面而来。若再配一盏门口的红灯笼（透明红 1×1 球 + 灯条），氛围能再上一个台阶。灯光兼容性给 **8/10**。

## 五、综合评分与购买建议

| 维度 | 得分 |
| --- | --- |
| 包装与零件 | 9/10 |
| 建筑结构 | 9/10 |
| 美食细节 | 8.5/10 |
| 灯光氛围 | 8/10 |
| 综合推荐 | ★★★★★ |

**结论：值得入手。** 这款**积木寿司店MOC**难度中等偏上（约 6 小时），对新手略不友好，但老玩家和街景党直接冲。它特别适合：

- 想给街景加"深夜食堂"氛围的玩家；
- 喜欢回转寿司、愿意自己加菜做扩展的玩家；
- 追求印刷件质感、讨厌贴纸的挑剔玩家。

不足主要是寿司品类偏少、二楼上楼方式单一（仅外挂梯）。但瑕不掩瑜，它仍是近期**街景美食主题**里完成度最高的一作。想看更多街景美食MOC的评测与图纸，欢迎访问 **brickplan.cn**，也记得常回 [BrickPlans 博客](https://brickplan.cn/blog) 看看后续的**积木寿司店MOC**专题。
