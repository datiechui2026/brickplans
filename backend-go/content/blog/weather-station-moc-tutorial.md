# 积木气象站MOC搭建教程：从观测场到百叶箱的完整指南

气象站是少有的"科学感"与"生活感"兼具的MOC题材。一架白色的百叶箱、高耸的风向标、旋转的风杯，往积木场景里一放，立刻就有"观测大自然"的味道。这篇**积木气象站MOC搭建教程**就带你把一座微型观测站从图纸变成实体。

## 一、整体规划：先定地盘再谈细节

气象站MOC建议采用 **1:48 比例**，底盘用 32×32 孔距的绿色底板，模拟一片标准观测场。布局上遵循真实气象站的"前后排"逻辑：前排放百叶箱和雨量筒，后排立风向标与风速杆，中间留出小径。这样既符合常识，也让成品有层次。

**配色定调**：主体以白色、浅灰为主（气象设备的经典色），搭配少量蓝色（模拟天空）和绿色（草地）。记住一个原则——设备越"素"，场景越真实。

## 二、核心结构：百叶箱是灵魂

百叶箱是气象站MOC最出彩也最考验细节的部分，建议优先搭建。

1. **底座**：用两块 4×4 板叠高约 8 个孔距，四角加 1×1 柱砖做支脚，保证箱子悬空——这正是真实百叶箱"离地通风"的结构。
2. **箱体**：用 1×4 白色板横条间隔错位排列做成"百叶"效果。这里有个技巧：每层百叶之间垫一层 1×1 薄板，留出通风缝，光线能透进去，效果才逼真。
3. **屋顶**：用两块 2×4 斜面砖（Wedge）对拼，形成人字顶，颜色用深灰色，与箱体形成对比。
4. **内部**：放一个白色温度计（可用 1×1 透明颗粒 + 细圆柱代替）和两个小人仔，仿佛值班员正在读数。

百叶箱做好的关键，是"缝隙均匀"——搭完从侧面看，百叶的间隙应笔直如一线，若歪了就是底砖没对齐，趁早拆掉重铺。

## 三、设备细节：风向标与雨量筒

**风向标**：用一根 1×16 科技轴做立杆，顶端十字销连接一个箭头状零件（可用 1×2 斜面砖拼装），尾翼用两片 1×1 光面板。杆子底部用 2×2 底座砖固定，确保大风（指你搬动时）也不会倒。

**雨量筒**：用两个透明蓝色 1×1 圆柱叠成，下方接一个白色漏斗件（可用 2×2 圆板加 1×1 内收过渡），放在一个深灰色小支架上。如果想做出"刚下过雨"的效果，在筒口附近散几颗透明蓝色 1×1 颗粒模拟水珠。

**风速杆**：顶端用三只 1×1 红色球关节件（Ball Joint）连接三个半球，做成三杯风杯，转动轴用科技十字销，能真正转起来，孩子会把玩上很久。

## 四、场景点缀与避坑清单

在观测场边缘加一圈白色矮栅栏（用 1×2 带孔砖 + 细杆穿插），放一棵小树和两块灰色石板铺路，气象站立刻"活"了。别忘了在底板一角加一块 2×4 白板当"记录牌"，用贴纸写上温度。

**避坑提醒**：
- 立杆类零件务必用底座砖压死，否则反复把玩易松脱；
- 透明件尽量少与有色件摩擦，容易划花，收纳时单独分装；
- 百叶箱悬空结构承重有限，顶部别再堆重物，保持轻盈才协调。
